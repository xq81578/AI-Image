# 时光对照创作工具

双击 `启动创作工具.vbs`，选择保存目录，配置已有文本/生图服务，填写目标合图数量后点击“一键生成”。`启动创作工具.bat` 可用于查看启动错误。

每组依次完成灵感、提示词、旧照、今照、本地合成和保存；各组并行推进。数量按最终合图计算，6 组会保存 6 张 1080×1920 PNG。旧照在上、今照在下，由本机仅叠加年份文字（例如“2001年”“2026年”），合成和保存不调用模型。

- 旧年份从 2000 年开始随机，以十年以上跨度为主；新年份为运行当年或前一年。每组年份确定后，重试不会改变。
- 旧照是手持纸质照片翻拍，彩照为主、少量黑白，做旧程度匹配保存年限；现在图引用旧照内部场景，直接呈现手机拍摄的现实画面。
- 并发数量在“并发与重试”中设置，仍受服务商额度与限流约束。临时接口错误最多自动重试 2 次，其余错误可手动重试。
- 暂停只停止后续步骤，已经发出的请求会继续接收结果。单组暂停不会影响其他组，整批恢复也不会解除单组暂停。
- 在详情中可查看原图、合图、提示词和配文。暂停一组并等待当前请求结束后，可以编辑提示词；修改旧照会重做两张图，修改今照会保留旧照。
- 合成或保存失败会保留已有图片，重试只处理失败步骤。同名同内容保存可安全重试，不覆盖其它图片。
- 最近一批的任务和图片缓存在当前浏览器。重新打开后可恢复已完成步骤；中断且未收到结果的请求需手动重试。浏览器清理网站数据会清除缓存，已保存文件不受影响。

“本地流程演示”使用带演示标识的本地图形，方便检查流程和保存目录，不调用付费模型。正式创作请选择对应生图服务。

本机服务仅监听回环地址，负责目录选择、公开图片下载与保存。默认仍打开原 `index.html` 文件位置，沿用该浏览器原有模型配置。请继续使用原浏览器；换浏览器或改为 HTTP 地址打开，配置与任务缓存属于不同存储位置。API Key 仍由页面直接发给配置的模型服务，不写入任务缓存或本机服务日志。

运行环境：Windows、`C:\Python313\pythonw.exe`（及同目录 `python.exe`）、Pillow。当前机器已具备。启动器使用脚本所在目录，可处理中文路径。

开发验证：

```powershell
node tests/batch-core.test.js
node tests/batch-prompts.test.js
node tests/model-transport.test.js
python -m unittest discover -s tests -v
```

无弹窗的本地流程验证：

```powershell
python server.py --no-browser --output-dir outputs\batch-qa --port 18765
```

打开 `http://127.0.0.1:18765`，选择“本地流程演示”即可验证实际合图落盘。该测试地址与日常文件页面的缓存、模型配置彼此独立。
